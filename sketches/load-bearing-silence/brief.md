# Load Bearing Silence

The third PHASE GARDEN concert study is a suspended brutalist crossing with its central member removed. Two angled, irregular remnants carry the composition across the page; a large paper void remains between their cut faces. One remnant supports a branching family of thin lamellar sheets, so the organic growth belongs to the structure rather than decorating the background. The drawing is an original visual response to the triptych brief's system building, reconstructed intervals, and structural silence. It does not depict an actual concert or artist billing.

The five physical inks have separate jobs. Carbon draws load edges and densely scored masonry; ultramarine continues the beam planes; vermilion marks stress at missing cuts; acid records sparse displaced events; violet runs through the branching lamellae. An oblique orthographic camera exposes front faces, undersides, and detached portal fragments. Every solid plane, including lamella ribbons, enters one shared CPU depth pass before strokes are classified. The art is clipped to x 18–279 mm and y 76–357 mm on A3 portrait paper; the concert lettering lives outside that field.

The **Composition** radar drives three native macros: Architectural load changes beam width and hatch spacing, Portal tension changes route bend and portal scale, and Disintegration changes gap width and branch reach. Branch root is an XY placement pad. Bridge world position moves the geometry in actual X, Y, and Z coordinates. The underlying scalar controls remain available for precise edits; the hidden-line toggle exposes the depth decision for inspection. Named seed streams vary route chirality, gap location, detached portal arrangement, and branch growth while retaining the material grammar.

Run `npm run sketch -- open sketches/load-bearing-silence/sketch.ts` to explore. A deterministic reference render is `node --import tsx cli/sketch.ts render sketches/load-bearing-silence/sketch.ts --seed 17 --out .sketch-output/phase-garden/load-bearing-silence/seed-17`. Seed 17 was inspected as a whole composition and rendered without diagnostics; the dedicated test checks repeatability, plot bounds, central emptiness, ink presence, controls, and minimum/maximum settings. These checks establish software behavior; the final judgment at physical pen scale still requires a plot.
